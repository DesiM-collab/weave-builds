Set up Weave

Weave puts your Android phone on your Mac and Windows PC: notifications, texts, calls, photos, files, the clipboard, the phone's screen, and full control of each computer from the others. Everything goes straight between your own devices, encrypted.

Step 1

Download the apps

Get the phone app, plus one for each computer you want to use. These links always point to the newest version.

Android phone galaxy-continuity-debug.apk Download for the phone → Mac GalaxyContinuity-mac.zip Download for Mac → Windows PC Weave-windows.msi · about 310 MB Download for Windows →
Step 2

Install on each device

Weave isn't in an app store, so each device asks once whether you trust it. That's expected.

Phone
  1. Open the downloaded .apk.
  2. If Android blocks it: Settings, then allow Install unknown apps for your browser.
  3. Tap Install.
Mac
  1. Open the .zip and drag Weave into Applications.
  2. Open it. macOS will refuse the first time.
  3. System Settings → Privacy & Security → Open Anyway.
Windows
  1. Run the .msi.
  2. If a blue “Windows protected your PC” box appears: More info → Run anyway.
  3. Weave opens and sits in the taskbar corner.

After this, updates are one click: each app shows A new version of Weave is ready with an Update button.

Step 3

Set up the phone

Open Weave on the phone. It walks you through three short screens. Nothing is shared until you switch it on.

  1. Allow notifications, so Weave can show that it's connected.
  2. Notification access (optional): lets you see your phone's notifications on your computers. You pick which apps.
  3. Battery → Unrestricted, so Samsung and other phones don't pause Weave when the screen is off.
Step 4

Pair a computer

Pairing links the phone and a computer with keys only they know. Do it once per computer, on the same Wi-Fi.

  1. On the computer, open Weave and click Pair phone. A code appears.
  2. On the phone, tap Scan pairing code (or Add computer in the menu).
  3. Point the camera at the code. Both screens say they're connected.

The code works once and expires after 2 minutes. Don't share a picture of it.

Have a Mac and a PC? Pair the phone with both. The phone then introduces them to each other, so they can share files and control each other too. Nothing else to do.
Step 5

Turn on what you want

Each feature asks for its own permission the first time. Turn them on in the phone app's Settings (menu → Settings) or from the computer when it asks.

Step 6 · optional

Connect from anywhere

At home, your devices talk directly over Wi-Fi. To use Weave from work or on mobile data, you add a relay: a tiny program in your own free Cloudflare account that passes data between your devices. It can't read anything: the data is encrypted before it leaves your device.

  1. Make a free account at dash.cloudflare.com (no card needed).
  2. Click the button below and follow Cloudflare's steps. It creates your own relay in your account.
  3. When it finishes, copy your relay's address. It looks like https://weave-relay.your-name.workers.dev.
  4. On each computer: Weave → Settings → Internet relay → paste the address and turn on Connect over the internet when away.
  5. Connect the phone to each computer once on Wi-Fi. They hand it the relay details. That's it.
Deploy your relay to Cloudflare

Personal use stays well inside Cloudflare's free plan. The computer you connect to must be awake.

If something's off

The phone can't find the computer

Make sure both are on the same Wi-Fi, and that Weave is open on the computer. On Windows, allow Weave through the firewall on private networks if Windows asked. Work and guest networks often block devices from seeing each other: set up the relay (step 6) for those.

Remote control of the Mac stopped working after an update

Open System Settings → Privacy & Security. Under Screen Recording and under Accessibility, select Weave, remove it with −, add it again with +, then reopen Weave.

Weave disconnects when the phone's screen is off

Phone Settings → Apps → Weave → Battery → Unrestricted. Weave's own Settings has a shortcut under Background operation.

Closing Weave on Windows

The X only hides the window; Weave keeps running in the taskbar corner so your phone can reach the PC. To quit, right-click the Weave icon there and choose Quit Weave.

It says "Connected over the internet" at home

It switches back to Wi-Fi by itself within about a minute. If it doesn't, the computer's firewall is probably blocking local connections; allow Weave on private networks.

Weave is a personal project. Pairing uses keys made on your own devices, and nothing passes through anyone else's servers: the optional relay runs in your own Cloudflare account.
